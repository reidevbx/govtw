# 參考

本設計系統在規劃與實作時參考其他國家的政府設計系統，以及以 Web Components 實作的元件庫。內容依台灣的語文、法規與使用情境調整，不是直接套用。

## 政府設計系統

- [GOV.UK Design System](https://design-system.service.gov.uk/) — 英國政府設計系統。元件、模式、文件結構與無障礙做法的主要參考。
- [U.S. Web Design System](https://designsystem.digital.gov/) — 美國聯邦政府設計系統。跨機關一致體驗、design token 與無障礙指引的參考。
- [New York State Design System](https://designsystem.ny.gov/) — 紐約州政府設計系統。以 Lit Web Components 服務跨框架機關的做法，與本系統技術取向相近。

## Web Components

- [Web Awesome](https://webawesome.com/) — 以 Web Components 實作的開源 UI 元件庫（前身為 Shoelace）。參考其元件 API、Shadow DOM 與無障礙實作。
