# 模式

## 什麼是模式？

模式（Patterns）說明如何組合多個元件，完成一件常見的使用者任務，例如修正表單錯誤、確認手機號碼。

| | 元件 | 模式 |
|---|---|---|
| 有沒有程式碼 | 有，可以直接安裝使用 | 沒有，只組合既有元件 |
| 回答的問題 | 這個元件怎麼用 | 要完成這件事，該用哪些元件、照什麼順序 |

有 GOV.UK 對應模式的，頁面會附上原文連結。

## 協助使用者
