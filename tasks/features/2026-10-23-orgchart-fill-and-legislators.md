# 組織圖：補齊漏列單位與加入立法委員

## 問題分析

- 上一輪三級機關只列「機關」，沒列「機構」（研究所、博物館、試驗所等）、國防部軍事機構，以及國安會副秘書長。
- 使用者要補齊這些，並加入立法委員 113 人。

## 需求定義

- 國安會副秘書長：加在 `core.json` 總統府 members，國安會秘書長之後。
- 國防部：參謀本部、陸軍／海軍／空軍司令部、憲兵指揮部、資通電軍指揮部，parent `mnd`。
- 三級機構：各部會所屬研究、試驗、博物館、圖書館、文化、訓練類機構，parent 為部會。不含醫院、學校、榮家與社福機構（教養院等）、國營事業、行政法人。
- 立法委員：依政黨分單位，parent `ly`，group null；單位 id `ly-party-<縮寫>`，成員 id `ly-member-<序號>`。
- 照片規則、來源規則同前；版面沿用區塊排法，不改程式。
- 驗收：`pnpm build:orgchart` 成功；版面檢查 0 重疊、全部單位有位置。
