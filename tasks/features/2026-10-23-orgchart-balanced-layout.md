# 組織圖：平衡版面（接近 16:9）

## 問題分析

- 全圖 4184×24000，太高。最高的是行政院「部」區塊（15 個部各帶三級機關，疊成一欄），其次是立法院（4 個政黨卡片疊成一欄）。
- 縮放到全圖時只剩細長條，下載倍率降到約 0.67。

## 需求定義

- 行政院所屬區塊可分多欄；自動選欄數，使全圖寬高比最接近 16:9。
- 子單位框（三級機關、立委政黨等）也可多欄：欄數加到框高 ≤ 框寬為止。
- 多欄排法：依序放進目前最矮的一欄（masonry），每欄寬度取該欄最寬的區塊。
- 驗收：`pnpm build:orgchart` 成功；版面檢查 0 重疊、全部單位有位置；回報新的全圖尺寸。

## 實作計劃

- [x] `layout.ts`：新增 `masonry(blocks, cols, gap)`，取代 `flow()`
- [x] `block()`：子單位欄數由 1 加到框高 ≤ 框寬
- [x] 行政院面板：列出各面板每種欄數的高度作為候選，逐一試算全圖寬高，選最接近 16:9 者
- [x] 建置、版面檢查
