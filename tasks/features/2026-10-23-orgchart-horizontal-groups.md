# 組織圖：行政院所屬分類區塊改為左右並排

## 問題分析

- 目前行政院底下 5 個分類區塊（行政院本部、部、委員會、其他機關、獨立機關）由上往下疊，靠左側一條主幹線連接。
- 使用者要改成左右並排，由行政院拉橫線連到各區塊；區塊內的機關由上往下排成一欄。

## 需求定義

- 5 個區塊在同一列左右並排，整列以 x=0 置中，頂端對齊。
- 連線：行政院卡片底部 → 往下到匯流線 → 橫線 → 各區塊頂端中點，同總統府連五院的畫法。
- 區塊內每個機關（含三級機關框）各佔一列，靠左對齊。
- 驗收：`pnpm build:orgchart` 成功；版面檢查 0 重疊、全部單位有位置。

## 實作計劃

- [x] `layout.ts`：移除 `PANEL_INNER_MAX`、`TRUNK_OFFSET` 與主幹線；先算出每個區塊，再一列置中排列；畫匯流線
- [x] 建置與版面檢查
