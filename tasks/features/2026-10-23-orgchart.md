# 中央政府首長組織圖（apps/orgchart）

## 問題分析

- 想做一張可以縮放、拖曳的中央政府組織圖，每個節點顯示首長照片、姓名、職稱。
- 資料只用官網公開的首長介紹頁。首長會異動，資料要記錄來源網址和查詢日期。

## 需求定義

- 範圍：總統府（總統、副總統）＋五院（院長、副院長）＋行政院所屬部會首長。
- 位置：monorepo 內 `apps/orgchart`，不修改 `packages/`。
- 技術：Vite + TypeScript + Konva.js（Canvas 套件）。
- 照片：下載到 `public/photos/`，每張在資料檔記錄來源網址。避免 canvas 跨網域污染（tainted canvas）。
- 驗收：
  - `pnpm build:orgchart` 成功。
  - 可滾輪縮放、拖曳平移，點節點會開官網來源頁。
  - 每位首長都有 `source`；沒找到照片的顯示姓名首字佔位。
